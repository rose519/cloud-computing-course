# Cloud Computing Reflection

Cloud computing has became part of my regular life in ways I hadn't expect. Most of the applications I rely on run through the cloud, and three that stand out are Google Drive, Facebook Messenger, and Canva. Storing school files feels effortless with Google Drive, while Messenger keeps me connected with friends and family. Canva, on the other hand, helps me put together presentations and graphic designs for class projects. Each one makes a different part of my life a little smoother.

Google Drive fits the definition of Software as a Service (SaaS) since I can use it right from a web browser or an app on my phone. There is no need to worry about looking after the hardware or software behind it. Its deployment model is Public Cloud because anyone with a Google account can hop on and use it from anywhere online. Facebook Messenger works the same way. It offers messaging services without users needing to install or run their own servers, which makes it a clear example of SaaS. Much like Google Drive, it relies on the Public Cloud model, with the provider hosting the service and millions of people sharing it. Canva is another good example of SaaS. Users get to design stuff online without downloading any professional design tools. Access happens through the internet, so Canva also runs on the Public Cloud deployment model.

Cloud infrastructure work really depends on version control, sort of like you need a trail of what went where and when. It essentially logs every change, to files and configurations, so if something goes off  path, you can bring back older versions without too much hassle. That helps lower the chances of data loss or system failures, which honestly is the part people care about most. In practice, Git is useful because it tracks changes on your local machine, and then GitHub steps in so the whole team can work together in the same shared online repository. GitHub also brings in stuff like branching, pull requests, code review, and the whole commit history thing, so everyone can handle different tasks at the same time, without trampling over each other’s updates. Plus it adds better communication, stronger accountability, and a cleaner way to organize the project over time. Overall, learning cloud concepts alongside Git and GitHub, together, has made it clearer to me how modern applications are developed, operated, and maintained in an efficient way, mainly through collaboration plus cloud technologies.
